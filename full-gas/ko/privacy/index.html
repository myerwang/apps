Full Gas

Full Gas 개인정보 안내 기기에 저장되는 데이터 캐릭터별 최고 거리, 플레이 기록, 마지막으로 선택한 캐릭터, 소리와 언어 설정을 이 기기에 저장합니다. 기기 백업에는 Apple 설정이 적용됩니다. 앱을 삭제하면 기기 내 데이터가 사라질 수 있습니다. 선택 사항인 Game Center Game Center를 이용하면 달린 거리를 Apple 서비스를 통해 제출합니다. Apple은 Game Center 플레이어 정보와 설정에 따라 점수를 처리하며 다른 플레이어에게 프로필과 순위를 보여 줄 수 있습니다. 이 기능은 게임을 멀티플레이로 바꾸지 않습니다. 로그인하지 않거나 서비스가 작동하지 않아도 일반 게임은 플레이할 수 있습니다. 광고와 결제 이 버전에는 광고, 앱 내 구입, 구독이 없으며 광고 추적이나 개발자 자체 분석 서비스를 사용하지 않습니다. App Store, Game Center, 시스템 진단에는 Apple 개인정보 처리방침과 시스템 설정이 적용됩니다. 문의 https://github.com/myerwang/apps/issues 에 문의하세요. Issue는 공개되므로 비밀번호, 신분 자료, 개인 저장 파일을 올리지 마세요. GitHub 계정과 웹사이트 데이터에는 GitHub 정책이 적용됩니다.
